# GDP and Life Expectancy Analysis

This project analyzes the relationship between income (GDP) and life expectancy across countries using R.

## Methods
- Data cleaning using tidyverse
- Visualization with ggplot2
- Linear regression analysis

## Key Findings
- Positive relationship between GDP and life expectancy
- Higher-income countries tend to have longer life expectancy
